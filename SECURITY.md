# Security policy

## What to report here

A security problem in anything this repository publishes:

- the validator (`_build/validate.py`);
- the data files in `data/` and the downloads on the website (for example a file that could harm the person who
  opens it);
- the website at https://aacf.adriansaxton.com.

## How to report it

Please report it privately: open the **Security** tab of this repository and choose **Report a vulnerability**. Do
not open a public issue for a security problem. You should get a reply within 14 days.

## Not security problems

A control, criterion or cross-reference that you think is wrong is not a security problem. Please open an issue for
it, as described in [CONTRIBUTING.md](CONTRIBUTING.md).

## Versions

Only the latest framework release is maintained. Fixes go into a new release, listed in CHANGELOG.md.
